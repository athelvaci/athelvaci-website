A lottery game implemented on the Ethereum blockchain. The rules live in a Solidity smart contract, so the game is completely decentralized and works without a central authority: nobody can change the rules or take the pot.

The web application is written in Vue.js and talks to the contract through MetaMask, which players need in their browser to join.
